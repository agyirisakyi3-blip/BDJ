    Aide
    
          
    Comment utiliser l'application de presence.
    
        
    
      
    

      
    
        
    1. Definir vos coordonnees
    
        
    Avant de scanner, ouvrez votre profil et saisissez votre nom et email. Vous ne le faites qu'une seule fois.
    
      
    

      
    
        
    2. Scanner le code QR
    
        
    Appuyez sur le bouton Scanner, pointez votre camera vers le code QR a l'entree du bureau. L'application detecte automatiquement si vous devez pointer l'entree ou la sortie.
    
      
    

      
    
        
    3. Pointage automatique
    
        
      
          
    • Premier scan = Entree (check-in)
      • 
          
    • Deuxieme scan = Sortie (check-out)
      • 
          
    • La duree de votre presence s'affiche en temps reel.
      • 
        
    
      
    

      
    
        
    4. Voir votre historique
    
        
    Appuyez sur Mon historique pour consulter vos pointages precedents, exporter en CSV ou effacer vos donnees.
    
      
    

      
    
        
    5. Mode hors ligne
    
        
    Si vous n'avez pas de connexion, le pointage est enregistre localement et synchronise automatiquement lorsque vous retrouvez le reseau.
    
      
    

      
    
        
    Questions frequentes
    
        
    Q : Le scanner ne s'ouvre pas ?
    A : Autorisez l'acces a la camera dans les parametres de votre navigateur.
    
        
    Q : J'ai oublie de scanner en sortant ?
    A : Demandez a votre admin de corriger votre pointage manuellement.
    
        
    Q : Mes donnees sont-elles privees ?
    A : Vos donnees restent sur cet appareil et dans la feuille de calcul du bureau. Aucune donnee n'est partagee avec des tiers.
    
      
    

      
    
    
  
    

  
    
    
    Cette application stocke des donnees localement sur cet appareil (profil, preferences, historique de presence). Aucune donnee n'est envoyee a des tiers.
